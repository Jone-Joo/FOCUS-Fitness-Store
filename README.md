# FOCUS Fitness Store

FOCUS is a static single-page fitness store website built with HTML, CSS, Bootstrap, and vanilla JavaScript.

## Features

- Full-screen FOCUS intro section
- Responsive dark fitness design
- Product cards with real images
- Training Day guide for gym machines
- Local image assets
- Mobile-friendly navbar
- No backend required

## Sections

- Intro
- Home
- Products
- About
- Training Day
- Footer

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5.3.8
- Vanilla JavaScript

## How To Run

Open `index.html` directly in your browser, or run a local server:

python -m http.server 8080
